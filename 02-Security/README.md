## 本章学习内容

本章介绍 MCP 系统中的主要安全风险、权限控制与安全设计原则。

建议重点理解：

- MCP Server 为什么需要限制权限；
- 工具调用、数据访问和认证可能带来的风险；
- 最小权限、输入验证和安全边界；
- 在实际 MCP 项目中如何减少不安全的工具调用。
