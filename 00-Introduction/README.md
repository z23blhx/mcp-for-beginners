## 本章学习内容

本章介绍 Model Context Protocol（MCP）是什么、为什么需要 MCP，以及 MCP 如何通过标准化接口让 AI 应用连接外部工具、API 和数据源。

建议重点理解：

- MCP 解决的核心问题；
- MCP Host、Client、Server 的基本关系；
- Tools、Resources、Prompts 的作用；
- MCP 为什么适合构建可扩展的 AI 应用。
