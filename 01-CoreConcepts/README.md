## 本章学习内容

本章重点解释 MCP 的核心架构与基本对象，包括 Host、Client、Server、Tools、Resources、Prompts 和 Transport。

建议重点理解：

- Host、Client、Server 分别负责什么；
- Client 如何发现 Server 暴露的能力；
- Tool、Resource、Prompt 的区别；
- stdio 与 Streamable HTTP 等传输方式；
- MCP 请求与响应的大致流程。
