## 本章学习内容

这是初学者最重要的实操模块之一。你会从环境配置开始，逐步完成 MCP Server、Client、LLM Client、测试与调试。

推荐学习顺序：

1. 创建第一个 MCP Server；
2. 编写 Client 并连接 Server；
3. 将 LLM 接入 Client；
4. 学习 stdio 与 Streamable HTTP；
5. 使用 MCP Inspector 测试 Tools、Resources 和 Prompts；
6. 再学习 Testing、Deployment 和 Authentication。
